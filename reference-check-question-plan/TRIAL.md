# Reference check question plan: tried once on its invented example

- **Product:** Claude, run in Claude Code
- **Model:** Sonnet 5.5 (model ID claude-sonnet-5-5)
- **Date:** 2026-11-10

The inputs are the invented example in `public/example.md` (Company A, Candidate K and five invented referees). No client data was used. This is one run by a model that did not write the template, and it says what happened, shortcomings included. It is not a test for a client.

## What I was given

The six inputs from the example, by reference: the reference stage record, the referee list (R1 to R5), the approved criteria (C1 to C5), the open points (P1 to P7), the operations director's four notes, and the people lead's topics never raised. I used the template's fenced instruction block and its output format, with the defaults (20-minute calls, 3 points per call, 2 referees per point), because the record says "default" for each.

One slip to record. I meant to read only the inputs before producing my output. My first command printed more of the file than I intended, and I saw the example's output header, its referee list, its points to test and the opening of its first call plan before I had written anything. So the plan below was not produced fully blind: the referee assignments (which referee gets which point) may have been influenced by what I had seen. I did work the assignment out again from the steps and got the same result, shown below. The question wording, the note sheets, the screening and the open questions were produced afterwards by me.

## What was observed

**Every required part was produced.** Header, referees, points, call plans, note sheets, coverage, review notes, open questions, sources and closing line. Nothing in the inputs made the template stop: consent and the authorising role were dated, the headers matched, no two rows shared a number, no referee list contact details or CV were present.

**Nothing was a stop condition,** but four things were declined, set aside or removed as the template says: the request to ring a person the candidate did not name (declined), the request for a yes or no (declined), the rehire question (not used), and the three open points that touch pay history, sick leave and "culture fit" (removed).

**Differences from the published example.** After producing my output I compared it with the example's.

- The referee assignments, the points, the coverage counts, the review-note counts and the four open questions agree. This agreement is weak evidence, because I had seen part of that output first (see above).
- Question wording differs throughout. The template fixes the structure, not the words, so this is expected. The example's follow-up for P1 asks which parts of the schedule Candidate K kept and which the project manager kept; mine asks who kept it day to day.
- Both order the open questions operations director, recruiter, people lead. I had been inclined to follow the Roles section (recruiter first), but I had already seen the example's order, so I cannot say what I would have chosen blind. The template says only "grouped by role".
- The example puts the opening and closing in each call plan; I wrote them once above and said all four calls use them. The template asks for them in each plan.
- The example's open question 2 suggests asking whether "another manager saw this work"; mine asks for "another referee who saw this". Neither is a fact; both are suggestions.
- The example's question about a disagreement says the assistants "disagreed about how work should be done or shared". "Or shared" is not in the inputs. The inputs say only that the panel had no example of handling a disagreement within the team. That is a small invented detail, in the published example, in a question.
- I found no fact in my own output that is not in the inputs, apart from the wording of questions, which has to be written.

**Where the instructions were ambiguous, or I had to guess.**

1. Step 6 orders points "from the one with the fewest referees who may be called now". I read this as the number of eligible referees who can be called now, not the number already assigned. The text does not say which. The result depends on the choice: with the other reading, the order changes.
2. The order of the groups in the open questions is not given ("grouped by role"). The Roles section lists recruiter, hiring manager, people lead, and the output format shows "For [role]" without an order.
3. The pay-history item must be "flagged for the people lead", but the output format has no open question for it, only a line in the removed list. It is unclear whether it also needs a numbered open question.
4. The stage record says "Call length: default", "Points per call: default" and "Referees per point: default". The template gives the defaults as 20, 3 and 2, but a reader has to connect the word to those numbers.
5. "Listen for" must be the criterion's description of clear evidence "word for word". That text says "the candidate kept themselves", while the questions say "Candidate K". Copying it exactly leaves the plan mixing two ways of naming the person.
6. The template says the main question is the same for every referee asked about a point. For P3 the same sentence goes to the manager and to the direct report ("the people Candidate K supervised"), which reads oddly to R5, who was one of those people.
7. For a point whose open question is "was it typical" (P2), the first follow-up and the fixed third follow-up ("did you see the same on other occasions?") ask nearly the same thing.
8. The opening is to be the same for every referee, but its bracketed "[recruiter role]" is filled from "Prepared for", which names the person the plan is prepared for. Those happen to match here.
